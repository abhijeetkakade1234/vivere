# Vivere PRD

## Product

Vivere is a PWA for planning experiences instead of isolated purchases.

The user starts with a moment:

- first date
- birthday
- movie night
- rainy evening

The product turns that intent into a plan with timing, venue ideas, add-ons, and clear next steps.

## Problem

People do not struggle to buy. They struggle to plan.

Typical commerce apps assume the user already knows what to order. Vivere starts one layer earlier by helping the user decide what kind of experience they want.

## MVP Outcome

A user should be able to answer a short intake, get a thoughtful plan, and feel like the hard part of deciding is done.

## Frontend Goals

- feel premium, calm, and guided
- ask one decision at a time
- make the plan easy to trust and edit
- keep the UI deterministic even when AI is involved

## Non-Goals

- chatbot-first UX
- dashboard-heavy navigation
- exposing provider complexity in the UI
